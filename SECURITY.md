# Security Policy

## Supported Versions

Cloudreve-New tracks the upstream 4.x line. Fixes land on the latest published
version only; older builds are not maintained.

## Reporting a Vulnerability

Report vulnerabilities privately through this repository's GitHub
**Security Advisories** (Security → Advisories → New draft advisory).

Do not disclose them in public issues, discussions, or pull requests.

Reports about inherited upstream code may also need to be coordinated with the
Cloudreve maintainers; we will tell you if that is the case.

## Scope notes

- This project does not ship or support any proprietary Pro binary or license
  server. Issues requiring those components are out of scope.
- Vulnerabilities in third-party storage drivers or the frontend dependencies
  should also be reported upstream.
