# Security Policy

## Supported Versions

Cloudreve-New follows the upstream 4.x line. Security fixes are applied to the
latest published sub-version only; older builds are not maintained.

## Reporting a Vulnerability

Please report vulnerabilities privately using this repository's GitHub
**Security Advisories** page (Security → Advisories → New draft advisory).

Do not disclose vulnerabilities in public issues, discussions, or pull requests.

You will receive updates through the advisory thread once the report is
confirmed. If the issue originates in upstream Cloudreve rather than in this
fork, we may coordinate disclosure with the upstream maintainers.
